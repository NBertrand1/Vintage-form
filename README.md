# Vintage Form

**Responsive login and sign-up frontend demo | Démo frontend de connexion et d'inscription**

## Français

Vintage Form est une maquette frontend responsive qui présente des formulaires de connexion et de création de compte.

### Fonctionnalités

- Bascule entre les formulaires de connexion et d'inscription
- Champs accessibles avec labels et validation HTML native
- Mise en page responsive
- Message explicite sur le statut de démonstration

**Limite :** aucun backend n'est connecté. Les formulaires ne créent pas de compte, ne vérifient pas d'identifiants et n'enregistrent aucune donnée.

### Lancer

Ouvrir `index.html` dans un navigateur ou utiliser un serveur statique local.

## English

Vintage Form is a responsive frontend mockup for login and sign-up flows. It includes accessible labels, native browser validation, and a switch between forms.

**Limitation:** no backend is connected. The forms do not authenticate users, create accounts, or store submitted data.

Open `index.html` in a browser or serve the folder with a local static server.
